<objective>
Deliver the no-LLM safety net: a pure-Python validator that checks each mapped field — and every ranked alternative — against the constraints the user declared, and forces any objection to needs-confirmation regardless of Claude's reported confidence or an auto-applied profile's 1.0. It reuses Phase 2's `canonical.assemble().flagged` as its type/date/text-unit engine (writing only the two checks Phase 2 never did: allowed_values and min/max), adds a `validator_note` so the tool's deterministic verdict stays visibly distinct from Claude's own reasoning, and threads a fail-closed-by-default strictness setting through (D-11).

Purpose: This is P1 made mechanical — "lives are at stake, so a declared constraint is checked on every value, on every path, and can only ever tighten the gate, never loosen it."

Output: `validation/` package, a new `FieldMapping.validator_note` field rendered in the CLI review, and validator wiring on both the Claude and auto-apply paths.
</objective>

## Phase Goal (user story)

**As a** data curator whose files can decide medical outcomes, **I want to** have every mapped value and alternative mechanically checked against the constraints I declared — with any violation forcing a human review no matter how confident the AI is — **so that** a plausible-looking wrong value can never slip through green.

After each task: (1) a violating value is mechanically flagged with a distinct tool note; (2) I can choose how much row coverage the check uses, safe by default; (3) the check runs even under a saved 1.0 profile, on every path.
