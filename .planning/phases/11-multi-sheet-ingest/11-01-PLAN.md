<objective>
Build the one genuinely new primitive of Phase 11: a per-sheet description of a workbook that sits ABOVE `parse()` (D-11-21). It reports, for every real worksheet, the name, the RESOLVED headers, the data-row count, and a structural status — and it marks a broken sheet rather than dropping it (SHEET-04: "a sheet that fails a gate is surfaced, never dropped").

Purpose: the sheet manifest and the Schema scorer both need per-sheet headers. Because `parse()` already short-circuits ranking when handed an explicit `sheet=` (`table.py:359-367`), building this ABOVE `parse()` means `parse()`, `_resolve_sheet`, `rank_sheets` and `SheetRanking` are NOT TOUCHED — every existing parsing test stays green, and SHEET-04 comes for free later (each per-sheet `parse(path, sheet=X)` already runs the full header/shape/locale/date chain on its own sheet).

Output: `describe_sheets(path) -> list[SheetDescription]` + `SheetDescription` + `SheetStatus` in `parsing/structure/sheets.py`, with a fixture-driven test suite.
</objective>
