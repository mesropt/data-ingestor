<objective>
Build SHEET-05's scorer: given one sheet's headers, rank the governed Schemas by coverage and say WHY, in pure Python, headers-only (D-11-04), with no LLM and no threshold. The ranking order is fixed (D-11-05): exact learned-profile hit first, then crosswalk alias coverage.

Purpose: today the human must pick a Schema from a dropdown *before* upload — file unparsed, no header seen. This inverts the order: parse first, propose per sheet second, human confirms third. The scorer is a **composition** of functions that already exist and are already tested (`_prefill_coverage`, `_vendor_agnostic_alias_index`, `field_set_from_schema`, `ProfileStore.find`, `column_signature`) — plus D-11-17, the one logic hole that must be closed for any of it to match a tidy header at all.

Output: `_covered_fields` (the extracted shared core), `SchemaProposal`, `propose_schemas_for_sheet`, and `describe_workbook` — the whole sheet manifest, assembled above `parse()`.

This plan defines the interface the sheet-question route (11-07) and the Claude ranker (11-05) both build against. `describe_workbook` takes `client=None` and `rank_fn=None` FROM THE START, even though this plan leaves the third stage unimplemented — so 11-07 can pass the client without a later signature change.
</objective>
