<objective>
Add the third and last stage of the Schema scorer (D-11-19): when both deterministic stages return zero coverage across every Schema, send that sheet's **headers** to Claude and let it rank the governed Schemas.

Purpose: this is not a departure from "Python before LLM" — it is D-10-03's Python → Claude → human ladder applied to the Schema choice. The cheap deterministic pass always runs first; an LLM call is only ever spent on what it could not resolve. D-11-06 is unchanged: Claude only *proposes*, the human confirms every sheet, nothing is auto-applied. `headers_only` remains honoured — Claude sees headers in both modes, which is all it ever sees here.

Output: `mapping/schema_ranker.py` (mirroring `mapping/mapper.py`'s skeleton exactly) and its wiring as stage 3 behind `describe_workbook`'s existing `client` / `rank_fn` seams.
</objective>
