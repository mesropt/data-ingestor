<objective>
Make every ingested row remember which sheet it came from (SHEET-03) — as a reserved export meta column, never a `Field` in the `FieldSet` (D-11-12).

Purpose: `source_sheet` as a `Field` would change `FieldSet.signature` and **every previously learned profile would silently stop matching** — the learning loop, the product's differentiator, would quietly break (D-11-13, confirmed at `service.py:1436-1440`). And an extra key smuggled into `CanonicalTable.records` behaves three different ways: `write_csv`'s `DictWriter` **raises**, `write_xlsx` **silently drops**, `write_json` **keeps** it (D-11-14). So the column must be explicit and threaded on purpose.

This plan is deliberately first (wave 1) and owns `service.py` / `state.py` / `confirm.py` for the phase's provenance concern only; the scorer (11-04) and the run group (11-07) build on top of it.

Output: `RawTable.origin_sheet`, `CanonicalTable.record_sources`, `assemble(*, source_sheet=None)`, all three writers + `build_manifest`, and the service/route wiring that fills the value on every ingest.
</objective>
