<objective>
Land the N-dataset Review (D-11-10, UI-SPEC §Discretion 2 — APPROVED and BINDING): all N at once, one Review with tabs, each member confirming on its own gate, and one action to download the archive.

Purpose: this is the surface where "N independent datasets, never merged" becomes something a human can actually work. The one correctness hazard is stated plainly by research and by the UI-SPEC: `Review.tsx` holds a curator's amber resolutions in local `useState` (`:85-86`), so a remounting tab **silently destroys their work**. Every tab pane is `forceMount`ed and hidden when inactive. That is a design requirement, not a nit.

Also closes SHEET-03's visible half: the provenance line on every ingest (single-sheet and CSV included — a traceability column that only sometimes exists is not a traceability column, and neither is its visibility).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server response → React render | Worksheet titles, header text and vendor names are untrusted content rendered in the tabs |
| group archive download | A client-triggered file download over an authenticated route |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-36 | Tampering | XSS via a worksheet title in a tab label | medium | mitigate | React escapes by default; titles render as text children only. No `dangerouslySetInnerHTML`. |
| T-11-37 | Denial of Service / data loss | a curator's amber resolutions destroyed by a tab switch | critical | mitigate | Every `TabsContent` is `forceMount`ed and hidden when inactive; each member's `Review` is keyed by its own stable token. Grep-asserted, and pinned by the human-verify checkpoint's step 2. |
| T-11-38 | Elevation of privilege | the group download bypassing a member's amber gate | critical | mitigate | The bar is enabled only when every member has confirmed; the server refuses the archive while any member has no `run_id`, and a `run_id` only exists because that member's own `NotReadyError` gate passed |
| T-11-39 | Information disclosure | a hidden member being silently forgotten | medium | mitigate | `TabsList` WRAPS rather than scrolls — every member stays visible; a hidden dataset is exactly what this phase exists to prevent |
| T-11-SC | Tampering | package installs | high | accept | Zero packages installed (`tabs` is already installed; the one approved add happened in plan 11-09). |
</threat_model>
