<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| uploaded/imported content → SchemaStore | schema names, vendor labels, source-column names, and imported field names are untrusted strings that reach SQL and (later) Claude's prompt |
| domain envelope → from_master_map | a master-map file's JSON is untrusted; its field names must pass the same name-safety guard as CLI-declared fields |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering (SQLi) | sqlite_schema_store.py queries | high | mitigate | Parameterised `?` placeholders only for every schema/field/alias/vendor value (mirrors sqlite_store.py ASVS V5); no f-string SQL |
| T-07-02 | Repudiation | alias provenance rows | high | mitigate | add_alias INSERT OR IGNORE on UNIQUE(canonical_field_id,vendor,source_column) — first-seen provenance_actor/created_at never overwritten (ALIAS-03) |
| T-07-03 | Tampering | Schema.from_master_map field names | medium | mitigate | Imported field names routed through fields.loader guard (_validated_name) — a newline/control char in a field name raises ValueError, never reaches a prompt |
| T-07-04 | Information disclosure | cross-schema data bleed | high | mitigate | schema_id / canonical_field_id foreign keys structurally isolate schemas (SCHEMA-04); no Python-side name filtering as the isolation mechanism |
| T-07-SC | Tampering | dependency supply chain | low | accept | No new package installs this plan — reuses stdlib sqlite3 + existing dataclasses; nothing to audit |
</threat_model>
