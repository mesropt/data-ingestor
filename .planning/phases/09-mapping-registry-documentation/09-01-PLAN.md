<objective>
Build the Mapping Registry: a new read-only tab that renders the whole crosswalk for a selected Schema — canonical fields on the left, each vendor's alias name(s) + provenance on the right (REG-01, REG-02). Realizes the "Profiles" tab descoped in v1.0, now backed by real crosswalk data.

Per D-09-02 this is FRONTEND-ONLY on top of Phase 07's existing endpoints: the Schema selector reads GET /api/schemas (listSchemas), and on select the screen fetches GET /api/schemas/{name}/master-map and renders its canonical fields + aliases. Per D-09-05 viewing is open (the master-map GET is not gated; only mutations are) — no sign-in wall on this read.

Split of concern: all pure data-shaping (grouping aliases under canonical fields, formatting provenance, humanising timestamps, deriving empty states) lives in a testable module `state/registry.ts` with vitest coverage (tdd, D-09-03); the React table + screen are thin presentational wrappers verified by tsc/build + an end-of-phase human visual pass.

Purpose: Surface the governed master + its data lineage — the "governed master, with lineage" demo story for judges.
Output: getMasterMap api wrapper, tested registry logic, RegistryTable + Registry screen, Registry tab wired into the shell.
</objective>

  <behavior>
    Pure module `state/registry.ts` (NO React import — vitest runs in the `node` environment, mirror state/schema.ts). Cases to cover in registry.test.ts:
    - groupFieldRows(envelope): given a MasterMapEnvelope, returns one row per canonical field IN THE ENVELOPE'S FIELD ORDER (never re-sorted), each with the field name + quiet metadata (type, unit, allowed_values/min/max when present) and its aliases list verbatim.
    - A canonical field with an empty aliases array yields a row flagged `hasAliases: false` (drives the "no vendor aliases recorded yet" empty state) — never dropped from the list.
    - formatProvenance(alias): provenance_kind "manual" → label "manual", source = provenance_actor (the user email); provenance_kind "from_map_file" → label "from map file", source = provenance_actor (the map file's source name). Return a structured object ({ kind, label, actor, when }) — NOT an HTML string — so the component renders each part as escaped text.
    - formatWhen(created_at): an ISO-8601 string humanises to a stable, locale-independent absolute form (e.g. "2026-07-11 14:32 UTC" or a documented Intl format); an empty/invalid created_at yields a safe fallback ("unknown date"), never throws.
    - isSchemaEmpty(envelope): true when the envelope has zero canonical fields OR every field has zero aliases (drives the whole-Schema empty state); false otherwise.
    - Unknown/unexpected provenance_kind values do not throw — they fall back to rendering the raw kind text as the label.
  </behavior>

Import MasterMapEnvelope from ./types (already exported).
