## Phase Goal

**As a** data curator, **I want to** define fields, upload a messy CRO file, resolve any structural hint and yellow fields, and confirm in the browser, **so that** the tool learns the format and auto-maps the next same-source file with no Claude call.

<objective>
Stand up the FastAPI transport layer and the first real browser-reachable capability: POST a file + field set, get back a validated mapping (or a structural question) as JSON. This is the phase's walking-skeleton slice — after this plan a real HTTP client can upload and receive Claude's proposed-and-validated mapping (API-01), and a matching profile auto-applies with no Claude call (API-03). Also wire `app.frontend()` so one `uvicorn` command serves the API and the built React bundle (the one-command demo).

Purpose: the API is a thin adapter over service.py (Plan 01). Route handlers only translate HTTP↔domain — materialize UploadFile to a temp path, call service.resolve_or_map, serialize the result, clean up. No mapping/validation/signature logic is written here.

Output: `api/app.py` (FastAPI instance, router includes, app.frontend mount, dev-only CORS), `api/deps.py` (DI seams), `api/wire.py` (Pydantic HTTP models), `api/state.py` (in-memory upload registry), `api/routes/upload.py`, and TestClient tests including the auto-apply no-Claude-call spy.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → /api/upload | Untrusted multipart file + form fields cross into the server |
| UploadFile → filesystem | Client-controlled filename could influence a path |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-04 | Tampering / Information Disclosure | UploadFile.filename → temp path | high | mitigate | Only the extension is derived from filename; the path is tempfile-generated (Task 2) |
| T-04-05 | Denial of Service | Unbounded upload size | medium | mitigate | Extension allowlist + max-size bounded read, reject before parse() (Task 2) |
| T-04-06 | Information Disclosure | Uploaded bytes left on disk | high | mitigate | try/finally os.unlink on happy path; registry TTL eviction for the structural-question path (P2, Task 1/2) |
| T-04-07 | Tampering | XXE via re-uploaded .xlsx | high | accept | Inherited mitigation — calls the same parse()/parse_file() that already uses defusedxml (Phase 1); no new Excel path introduced |
| T-04-08 | Spoofing | /api/* shadowed by SPA fallback | low | mitigate | app.frontend() registered last; route-not-shadowed regression test (Task 3) |
| T-04-21 | Information Disclosure | cell values sent to Claude on the mapping path under headers_only | high | mitigate | headers_only threads to service.resolve_or_map → propose_mapping; Task 2 test asserts no cell values reach the fake mapper under the toggle (P2). The structural-hint path has no Claude call site (W1), so it needs no separate guard |
