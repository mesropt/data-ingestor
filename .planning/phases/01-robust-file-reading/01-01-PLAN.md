<objective>
Deliver the CSV vertical slice AND the structural-contract spine the whole phase reuses: a messy CSV (semicolon delimiter, leading comment lines, comma decimals) reads as a clean table end-to-end, and a genuinely ambiguous decimal column surfaces a returned `StructureQuestion` instead of a silent guess.

This plan establishes the three-layer pipeline's two non-Claude layers (D-01 layer 1 = deterministic heuristics, D-01 layer 3 = human-confirmation contract). The Claude assist layer (D-01 layer 2) is added in plan 05; until then the deterministic layer works fully with no API key (D-04).

Purpose: Every later slice (header detection, sheet selection, shape) returns the SAME `StructureQuestion` object defined here and flows through the SAME `parse()` entry and CLI ask-branch. Getting this contract right first is what makes plans 02-05 thin.
Output: `hint.py` (StructuralHint, StructureQuestion, enums), `structure/delimiter.py`, `structure/locale.py`, a `parse()` entry returning `RawTable | StructureQuestion`, per-column locale annotation on `RawTable`, and the CLI ask-branch.
</objective>

## Phase Goal (MVP user story)

**As a** data curator, **I want to** have the tool read my messy CRO file's structure correctly — or ask me one clear, pre-filled question when it genuinely cannot — **so that** I never receive a silently-wrong table and never hit a crash.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Denial of Service | parse() on malformed/unusual CSV | medium | mitigate | Structural uncertainty returns a StructureQuestion (D-05); only genuinely broken files (missing path, unsupported suffix) raise the existing FileNotFoundError/ValueError — the parser never crashes on merely unusual structure. |
| T-01-04 | Tampering (of output) | locale annotation guessing a decimal separator | high | mitigate | The ambiguity rule (D-14) refuses to guess a 1000x-corrupting decimal separator: uniform 3-digit-after-comma columns are flagged ambiguous, not silently converted. Conversion itself is deferred to Phase 2 (D-15), so Phase 1 cannot corrupt a value. |
</threat_model>
