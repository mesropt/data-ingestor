<objective>
Complete the three-layer structure-resolution pipeline (D-01) by adding layer 2: a Claude structural PROPOSAL that pre-fills a StructureQuestion when the deterministic heuristics are not confident, so the human confirms a pre-filled answer (one click) rather than diagnosing the file themselves — a better DEMO-03 beat without weakening the gate. Claude NEVER applies a structural answer itself (D-02).

This plan is deliberately last: layers 1 (deterministic) and 3 (human confirmation) already ship in plans 01-04 and work fully with no API key (D-04). If time runs out here, the tool still resolves structure and asks the human from raw evidence — this layer only makes the question pre-filled and prettier.

Purpose: D-02's rationale — a wrong structure looks perfectly clean downstream, so structural resolution is the one place silent auto-apply is least acceptable; Claude proposes, the human disposes, exactly one layer earlier than the mapper.
Output: `structure_schema.py` (wire model), `structure_assist.py` (isolated Claude call, injectable client), and the wiring that lets a not-confident StructureQuestion carry a Claude pre-fill.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted cell content → Claude structural proposal | Raw-grid evidence (cell values) from an untrusted file is sent to Claude; a cell could be engineered to read like an instruction (prompt injection). |
| Claude proposal → structure resolution | The model's proposed structure crosses into the resolution path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-02 | Tampering | prompt injection via cell content steering the structural proposal | medium | mitigate | D-02: Claude's proposal is NEVER auto-applied — it only pre-fills a question the human confirms against the raw evidence rows. A malicious file can at worst mis-pre-fill; it cannot resolve structure. This is exactly the failure mode D-02's design was written to prevent. |
| T-01-10 | Denial of Service | SDK call failure / missing credentials during structural assist | low | mitigate | The Claude layer is optional (D-04); a missing key or API error degrades to the deterministic StructureQuestion (reuse _map_one's AuthenticationError/APIError handling), never a crash. |
</threat_model>
