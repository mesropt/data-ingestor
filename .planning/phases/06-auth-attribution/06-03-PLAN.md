## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| React UI → FastAPI | The UI gate is a UX mirror only; the server (plan 06-02) is the real enforcement point (P1) |
| di_session cookie ↔ browser | HttpOnly means JS cannot read it; the frontend never handles the raw token, only credentials:'include' |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-12 | Elevation of Privilege | ConfirmGate UI gate | medium | mitigate | The disabled/enabled button is a mirror only; server require_verified_user re-checks every confirm (plan 06-02) — a tampered client that force-enables the button still gets 401/403 from the endpoint |
| T-06-13 | Information Disclosure | session token exposure to JS | high | accept | Cookie is HttpOnly (set server-side, D-06-01); the frontend deliberately never reads or stores the token, relying on credentials:'include' — no client-side token handling to leak |
| T-06-14 | Spoofing | trusting a client-held "verified" flag | medium | mitigate | isGovernedActionAllowed reflects the last server-resolved user only; the authoritative verified check is server-side on /api/confirm, never the UI selector |
| T-06-15 | Tampering | Google brand-asset misuse | low | accept | Generic Chrome placeholder icon documented (06-UI-SPEC Registry Safety FLAG); real brand asset required before any public flag-on use — noted, not a runtime risk overnight (flag off by default) |
</threat_model>
