<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → POST /api/confirm | A governed action; the gate must be enforced server-side on the endpoint, never trusted from the client (P1) |
| browser → POST /api/auth/login | Untrusted credentials cross here; verified against the stored Argon2 hash only |
| Google redirect → /api/auth/google/callback | OAuth authorization-code/state/nonce round trip (only when the flag is on) |
| confirm body `confirmed_by` (absent by design) | Identity for AUTH-04 must come from the require_verified_user-resolved User, never a client field |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06 | Elevation of Privilege | POST /api/confirm gate | high | mitigate | require_verified_user Depends returns 401 (signed out) / 403 (unverified) BEFORE any confirm work; asserted by test_confirm_auth_gate.py — the gate is on the endpoint, not the UI |
| T-06-07 | Spoofing | confirmed_by attribution | high | mitigate | confirmed_by is taken from the server-resolved user.email inside the route, never read from the request body (ConfirmRequest has no such field) |
| T-06-08 | Spoofing / Tampering | Google OAuth state/nonce | medium | mitigate | Authlib authorize_redirect/authorize_access_token validate state+nonce internally (Don't-Hand-Roll); SessionMiddleware backs the transient handshake state only, added only when the flag is on |
| T-06-09 | Information Disclosure | verification link / password in logs | high | mitigate | Only the verification URL (a signed, expiring token) is logged — never the password; grep gate in Task 1 |
| T-06-10 | Spoofing | CSRF against the confirm POST | medium | accept | SameSite=Lax cookie (set in Task 1, locked by D-06-01) blocks cross-site POST cookie attachment; no synchronizer token added at ASVS L1 |
| T-06-11 | Spoofing | credential stuffing / brute-force login | low | accept | No rate limiting at ASVS L1 (D-06-03 "do not over-engineer"); recorded as a known gap for a future phase, not silently ignored |
</threat_model>
